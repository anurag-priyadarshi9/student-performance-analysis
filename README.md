# Student Performance Analysis

A Data Science project that analyzes student academic performance using Python and Excel.

## 📌 Project Overview

This project analyzes student marks, attendance, and examination performance to identify overall academic trends.

## 🎯 Objectives

- Analyze student academic performance
- Calculate total marks and percentage
- Identify pass and fail students
- Analyze attendance and performance
- Visualize student performance using charts

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Excel

## 📊 Dataset

The dataset contains student information including:

- Student ID
- Name
- Gender
- Attendance
- Assignment Marks
- Midterm Marks
- Final Exam Marks
- Total Marks
- Percentage
- Result

## 📈 Visualizations

The project includes:

- Percentage Comparison
- Result Distribution
- Attendance vs Percentage
